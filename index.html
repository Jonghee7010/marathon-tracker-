🏃 크루 라이브 트래커 --:--:--
설정에서 카카오 JavaScript 키를 입력하면
지도가 표시됩니다.

설정

① developers.kakao.com → 내 애플리케이션 → 앱 만들기
② 앱 설정 → 플랫폼 → Web 사이트 도메인에 이 페이지를 띄울 주소 등록
   (예: https://내아이디.github.io, 로컬 테스트는 http://localhost:5500)
③ 앱 키에서 JavaScript 키 복사
④ 제품 설정에 카카오맵 항목이 있으면 사용 설정을 켜기
⚠ 파일을 더블클릭해서(file://) 열면 도메인 등록이 안 되어 지도가 뜨지 않아요. 


  
여기서 바꾼 값은 이 화면에서만 임시로 적용돼요(새로고침하면 사라짐). 모든 접속자에게 적용하려면 “DEFAULTS 코드 복사”를 누른 뒤 index.html의 const DEFAULTS={…}; 부분을 그 내용으로 교체하세요.
